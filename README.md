# Поиск клиентов

Приложение для macOS: ищет локальный бизнес без сайта, отсеивает мусор через
Gemini и готовит по два сообщения на каждого. Отправку делаешь ты сам, программа
никому ничего не шлёт.

Окно нативное (Cocoa/WKWebView), интерфейс внутри него собран на HTML и CSS.
Это не браузер и не вкладка: страница лежит на диске, а с ядром общается через
внутренний мост, а не по сети. Тема подхватывается системная, светлая и тёмная.

## Запуск на Windows

Нужен Python 3.10 или новее с python.org. При установке обязательно отметь
галочку **«Add python.exe to PATH»**, иначе запуск не найдёт Python.

Дальше двойной клик по **«Поиск клиентов.bat»**. Первый запуск сам создаёт
окружение и ставит зависимости, это занимает пару минут. Последующие
открываются сразу.

Если Windows покажет синее окно «Защита компьютера», это SmartScreen реагирует
на незнакомый файл: «Подробнее» и «Выполнить в любом случае».

Окно рисуется через WebView2. В Windows 11 он есть всегда, в Windows 10 обычно
тоже; если приложение не открывается, поставь
[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
(нужен Evergreen Standalone Installer).

## Сборка exe на Windows

Кросс-компиляции у PyInstaller нет: exe собирается только на Windows.

Двойной клик по **«build-windows.bat»**, либо вручную:

```
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean lead-finder.spec
```

Результат в `dist\ПоискКлиентов\`. Папку можно целиком переносить на другой
компьютер, Python там уже не нужен.

Настройки, ключ и база лидов в собранной версии лежат рядом с exe, а не внутри
него, поэтому переживают перезапуск и обновление сборки.

## Запуск на macOS

Двойной клик по **«Поиск клиентов.command»**.

Первый запуск, если папка только что скачана:

```bash
cd lead-finder
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Ключ

Нужен ключ Gemini, бесплатный, берётся в Google AI Studio. Вставляется
в разделе «Настройки», хранится в файле `.env` рядом с программой и никуда
больше не отправляется.

## Окно

Слева навигация и воронка: сколько лидов на каждом этапе. Внизу строка
состояния. Сохранение по Cmd+S работает на любом экране.

Города выбираются из встроенного справочника: 1229 городов и посёлков Украины,
выгруженных из OSM, поэтому написание гарантированно совпадает с тем, по
которому потом идёт поиск. Поле ищет и по привычному написанию: «львов» найдёт
«Львів», «николаев» найдёт «Миколаїв», прежние названия вроде «кировоград» тоже
работают. Городов можно выбрать сколько угодно, рядом кнопки «10 крупнейших» и
«Областные центры». Своё название вписать тоже можно, список это подсказка,
а не ограничение.

**Поиск.** Ниша, города, источники и лимит. Кнопка
«Пройти всё целиком» делает все четыре шага подряд, рядом те же шаги по
отдельности. Ниже лог: видно, сколько объектов вернул источник и почему часть
отброшена.

**Лиды.** Слева список с оценками, справа выбранный лид: оба сообщения, их
можно править и сохранить.

Ряд отправки подстраивается под контакты лида: WhatsApp, Telegram и Viber
появляются при наличии телефона, Почта при наличии адреса. В WhatsApp и в письмо
текст подставляется сам. Telegram и Viber так не умеют, в их ссылках просто нет
поля для текста, поэтому при клике сообщение кладётся в буфер и остаётся
вставить его в чат.

Ниже служебные кнопки: сохранить правки, переписать сообщения заново только
этому лиду, открыть профиль или карту, отметить отправленным, убрать в отсев.
Отметка об отправке хранится в базе.

Кнопка «Загрузить свой список» принимает CSV. Колонки распознаются по
заголовку, русские и украинские названия тоже: название, телефон, город, почта,
ниша, адрес. Порядок столбцов и лишние колонки значения не имеют, записи без
контактов пропускаются.

**Сообщения.** Здесь задаётся, что именно пишет модель. Три режима:

- *Мой шаблон, модель подгоняет под каждого* (`hybrid`): текст остаётся твой,
  но перестаёт выглядеть рассылкой. Обычно нужен этот.
- *Только мой шаблон* (`template`): подставляются плейсхолдеры, ИИ не
  используется. Бесплатно и мгновенно.
- *Модель пишет сама* (`ai`): шаблон игнорируется, модель опирается на задачу,
  стиль и примеры.

Блок «Что модель знает о тебе» задаёт факты, которые разрешено использовать:
выдумывать сверх этого списка запрещено промптом. Те же ключи работают как
плейсхолдеры в шаблоне: `{name}`, `{city}`, `{offer}`, `{price_from}`.

Стиль проверяется после генерации: лимит символов, запрет эмодзи, запрет
длинного тире, список запрещённых штампов. Нарушения попадают в причину у лида.

**Настройки.** Ключ и его проверка, модель, порог оценки, свои правила отсева
обычным текстом, страна номеров и лимиты обращений к Gemini. Правила важнее
встроенных, например:

```
Не бери сетевые салоны и франшизы.
Выше цени тех, у кого есть Instagram.
```

## Как устроен конвейер

1. **Поиск** собирает бизнесы и сразу отбрасывает тех, у кого в карточке есть сайт.
2. **Проверка контактов** приводит телефоны к виду `+380...`, определяет тип
   номера, проверяет, живой ли сайт, и склеивает дубли из разных источников.
3. **Проверка сайтов** спрашивает у Gemini с доступом к поиску, нет ли у бизнеса
   сайта на самом деле. В карточке OSM поле website заполняют редко, поэтому
   «нет сайта» там часто означает лишь «не записан», а написать такому «у вас
   нет сайта» это худшее начало разговора.
4. **Отсев** отдаёт список Gemini, и тот выкидывает банкоматы, сети,
   госучреждения, битые записи и всё, что не покупает сайт.
5. **Сообщения** пишутся по твоим шаблонам, по два на лида.

### Городские номера

У городского номера не бывает аккаунта в WhatsApp, Telegram или Viber, поэтому
кнопка «написать» на нём бесполезна. Такие лиды уходят в отсев сразу, если у них
нет почты или соцсетей; если есть, лид остаётся, но вместо мессенджеров ему
предлагается звонок.

Это заметно режет выдачу: в OSM у малого бизнеса чаще записан именно городской.
Если хочется видеть всех, поставь `drop_landlines: false` в `config.yaml`.
Мобильных номеров заметно больше в Google Places и в профилях соцсетей.

### Что было дальше

После отправки у лида отмечается исход: ответил, думает, клиент, отказ. Рядом
заметка и дата следующего касания, которая проставляется автоматически через
`followup_days` после отметки об отправке. Фильтр «На сегодня» показывает тех,
кому пора написать второе сообщение. Отказ и сделка закрывают переписку, и
напоминание снимается.

Всё лежит в SQLite (`data/leads.db`), поэтому повторный запуск не плодит дубли
и не переписывает готовое.

## Источники

**OpenStreetMap** (включён). Открытые данные, ключ не нужен. Лучший источник для
этой задачи: в карточке есть поле website, и его отсутствие это прямой сигнал.

**Google Places.** Официальный платный API, не скрапинг выдачи. Нужен ключ
`GOOGLE_MAPS_API_KEY` в `.env` и включённый Places API (New).

**Каталоги фирм.** Парсер по CSS-селекторам, которые задаются в `config.yaml`:
вёрстка каталогов меняется часто, и править конфиг быстрее, чем код.

**Соцсети.** Профили ищутся через публичную поисковую выдачу. Ни логина, ни
обхода защиты: Instagram и Facebook закрывают карточки от неавторизованных
запросов, а их правила запрещают автоматический сбор. Берётся только то, что
отдал поиск, поэтому есть ли у такого лида сайт, придётся смотреть глазами.
Шума от этого источника больше, чем от остальных.

## О чём стоит помнить

Холодные сообщения регулируются законом о рекламе и правилами мессенджеров.
Массовая автоматическая рассылка приводит к блокировке номера, поэтому её здесь
нет: кнопка открывает WhatsApp с готовым текстом, отправляешь ты и видишь, кому.

Перед отправкой читай текст. Модель иногда выдумывает детали о клиенте, хотя
в промпте это запрещено.

Данные OSM распространяются под лицензией ODbL, у Google Places свои условия.

## Если что-то не работает

**Overpass возвращает пусто.** Зеркал пять, запрос повторяется тремя кругами
с паузами, а удачный ответ кладётся в кэш на сутки. Если всё равно пусто,
проверь написание города: `Вінниця`, а не `Винница`.

**Мало лидов.** В OSM у многих точек нет телефона, такие записи отбрасываются,
потому что писать некуда. Помогает второй источник или свои теги в `config.yaml`.

**Gemini отвечает 429.** Это лимит запросов. Уменьши «запросов в минуту»
в настройках, у бесплатного ключа квоты низкие. У шага с веб-поиском квота
отдельная и более строгая, его можно запустить позже кнопкой «Проверить сайты».

**Gemini отвечает 503.** Модель перегружена у всех сразу, это бывает с самыми
свежими версиями. Запрос повторяется шесть раз с растущими паузами, а если
не помогло, работа продолжается на запасной модели из `gemini.fallbacks`
и в логе появляется строка о переходе.

**Ответ обрезается.** Уменьши `gemini.batch_size` в `config.yaml`.

## Из чего собрано

- `leadgen/` — ядро: источники, проверка, обращения к Gemini, экспорт. Про окно
  ничего не знает и работает само по себе.
- `app/` — мост: настройки, шаги конвейера и фоновые задачи, которые дёргает
  интерфейс.
- `ui/` — сам интерфейс: `index.html`, `styles.css`, `app.js`.
- `lead-finder.spec` — сборка через PyInstaller, под ту ОС, где запущена.

Платформенного кода почти нет: отличаются только показ файла в проводнике
и способ запуска. Windows, macOS и Linux работают с одной и той же кодовой базы.

Правки в `ui/` видны после перезапуска окна. Веб-инспектор открывается так:

```bash
LEADFINDER_DEBUG=1 .venv/bin/python3 run.py
```

## Тот же конвейер из терминала

Логика лежит в пакете `leadgen` и работает без окна:

```bash
.venv/bin/python3 -m leadgen run --open
.venv/bin/python3 -m leadgen scrape --city "Одеса" --limit 50
.venv/bin/python3 -m leadgen stats
```
